Travel Website Project


This project is a one-page travel website designed to showcase a combination of HTML, CSS, JavaScript, and Python skills. It focuses on creating a visually appealing and functional website with smooth interactions and basic validation.

Project Purpose


The goal of this project is to demonstrate my skills in frontend and backend development, showcasing:

-HTML & CSS for content layout and design


-JavaScript for dynamic interactions


-Python for basic input validation


Key Features

Smooth Navigation:
The navigation links scroll smoothly to different sections on the same page, enhancing the user experience.

Interactive UI Components:
The website uses CSS and JavaScript to create a polished and responsive interface.

Input Validation:
A Python script (validation_tool.py) that provides backend validation to ensure any form or input data is clean and error-free.
