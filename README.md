TRAVEL WEBSITE PROJECT


This project is a one-page travel website designed to showcase a combination of HTML, CSS, JavaScript, and Python skills. It focuses on creating a visually appealing and functional website with smooth interactions and basic validation.

PROJECT PURPOSE


The goal of this project is to demonstrate my skills in frontend and backend development, showcasing:

-HTML & CSS for content layout and design


-JavaScript for dynamic interactions


-Python for basic input validation


KEY FEATURES

Smooth Navigation:
The navigation links scroll smoothly to different sections on the same page, enhancing the user experience.

Interactive UI Components:
The website uses CSS and JavaScript to create a polished and responsive interface.

Input Validation:
A Python script (validation_tool.py) that provides backend validation to ensure any form or input data is clean and error-free. It checks basic details like names, email addresses, and phone numbers to ensure correctness before further processing or storing.
Key Features
-Validates User Names
-Checks Email Format
-Ensures Phone Numbers are 10 Digits

NOTE on validation_tool.py file:
The Python file is included to demonstrate my ability to work with Python for data validation. While it is not currently connected to a running backend or functional form on the website, it serves as an example of how I can integrate Python into a project for server-side logic in the future.
